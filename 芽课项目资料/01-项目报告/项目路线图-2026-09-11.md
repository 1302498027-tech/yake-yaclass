# 芽课 · 产品路线规划

> 更新：2026-09-11 ｜ 北极星目标：**一个不依赖个人电脑、每天自动更新的 PM 入门学习平台**

---

## 现状基线（已完成 ✅）

- **芽课工作台**：8 个原生视图（数据中台/今日总览/知识档案/每日自测/学习进度/每周总结/收藏夹/质量看板），科幻视觉 + 开场动画，移动端适配
- **内容管线**：三个每日自动任务（深度版/轻量版/技术版），META 格式统一，板块归类硬约束，✅/❌ 能力边界标注
- **数据层**：SQLite（打卡/收藏/答题/笔记四张表）+ REST API，前端双模式（服务模式落库 / 文件模式 localStorage 兜底）
- **发布链路**：本机自动任务 → 21:40/21:50 自动部署公开链接（快照式）
- **入口**：桌面快捷方式（新图标）+ 公开链接
- 知识点 54 条 ｜ 题库 24 题 ｜ 勘误记录 5 条 ｜ PRD 已立

## 阶段 2 · 上云 · 免费路线（第 3-4 周）⭐ 关键跃迁

> 目标：**电脑关机一周，系统照常每天更新**。目标成本 ¥0/月。

| 工作项 | 方案 |
|---|---|
| 日报生成脚本化 | 三个日报任务改写为 Python 脚本直调 GLM-4-Flash（免费模型），prompt 复用已加固的归类/边界硬约束 |
| 定时工作流 | GitHub Actions × 3：21:00 生成 → 21:40 构建部署 → 21:50 质检（每月 2000 分钟免费额度内） |
| 托管 | GitHub Pages（免费） |
| 数据同步（可选） | Supabase 免费档（500MB Postgres + 登录），手机答题同步云端 |
| PDF 转换 | 云端改用 Playwright/Chromium headless（Edge 方案不可移植） |

**验收标准**：连续 7 天电脑关机，公开链接每天 21:00 后照常出现当日三份新日报与质检报告。
**已知代价**：GitHub Pages 国内访问不稳定；GLM-4-Flash 深度略浅。

- **桌面端打包**：pywebview + PyInstaller → 独立 exe（图标已备好）

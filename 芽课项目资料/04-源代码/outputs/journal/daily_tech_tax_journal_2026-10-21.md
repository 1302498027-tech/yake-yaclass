## 2. 数智财税基础章节【工作台key:chapter_tax】
>面向PM：懂业务规则、系统流程、风险点，不做会计做账。
### 今日知识点：
1. 核心概念：
   - 数电票：电子发票
2. 业务场景举例：电商、餐饮、服务业等需要开具发票的场景
3. ✅ PM必须掌握：
    - 了解数电票的基本概念和流程
    - 识别数电票应用中的风险点
4. ❌ PM不需要深入：
    - 数电票的技术实现细节
5. 业务风险&产品设计注意点：
    - 保障发票数据安全，防止信息泄露

## 3. AI产品基础章节【工作台key:chapter_ai】
>面向PM：懂能力边界、适用场景、局限性，不用钻研算法原理。

   - 人工智能：模拟人类智能行为的系统
2. 现实产品落地案例：

3. ✅ PM必须掌握：
    - 了解AI在数据分析中的能力边界
    - 识别AI在数据分析中的适用场景
4. ❌ PM不需要深入：
    - AI算法的原理和实现
5. 产品需求设计、需求评审注意事项：
    - 确保AI应用符合业务需求

## 4. 数据库基础章节【工作台key:chapter_db】

## 5. SQL PM必备基础章节【工作台key:chapter_sql】
>面向PM：看得懂简单SQL逻辑、理解取数逻辑，不要求手写复杂生产SQL。
### 今日知识点：
1. 概念/语法通俗讲解：
   - SQL：结构化查询语言
2. 业务场景：产品需要数据分析时
3. 简单示例（极简，适合阅读）：
   - SELECT COUNT(*) FROM orders;
4. ✅ PM必须掌握：
    - 理解SQL的基本语法
    - 使用SQL进行基础数据查询
5. ❌ PM不需要深入：
    - SQL高级查询技巧
6. PM提取数需求、和数据同学沟通避坑提示：
    - 明确数据需求，避免数据不准确
